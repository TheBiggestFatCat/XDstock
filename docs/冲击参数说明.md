# 市场冲击参数说明

> 这份文档解释「玩家大单怎么推动价格」，以及每个参数调整后会发生什么。

## 一、机制总览

```
玩家成交 → 产生「压力」→ 每轮按压力推动价格 → 压力逐轮衰减
```

具体流程：

1. 你把一笔单子成交了，系统按**成交额**往这只票上记一笔「压力」
2. 每一轮（5 秒）价格按当前压力往前推一点
3. 推完压力衰减一档，下一轮推得少一点
4. 直到压力衰减到几乎为零

**关键点：压力按成交额算，和杠杆无关。** 用 20 倍杠杆买 1000 股和 1 倍买 1000 股，产生的压力完全一样。

---

## 二、五个参数

| 参数（面板名） | 字段名 | 默认 | 作用 |
|---|---|---|---|
| 参考成交额 | `playerImpactRef` | 100000 | 多少成交额算「1 单位压力」 |
| 推力系数 | `playerImpactStrength` | 0.0004 | 1 单位压力每轮推动多少价格 |
| 每轮衰减 | `playerImpactDecay` | 0.88 | 压力每轮保留多少 |
| 后续影响倍率 | `playerImpactTail` | 1 | 第 2 轮起打的折扣（**新增**） |
| 单轮最大影响 | `playerImpactMax` | 0.04 | 单轮最多推动多少（防止插针） |
| 压力上限 | `playerImpactFlowMax` | 12 | 压力最大能堆到多少 |

### 1. 参考成交额 `playerImpactRef`

```
压力增量 = 成交额 ÷ 参考成交额
```

- 参考额 **10 万**：一笔 10 万的单子产生 1 单位压力
- 调**小**（如 5 万）→ 同样的单子压力翻倍，价格更敏感
- 调**大**（如 30 万）→ 同样的单子压力只有 1/3，大单也不容易推动

### 2. 推力系数 `playerImpactStrength`

```
每轮推动 = 压力 × 推力系数
```

- 0.0004 = 每单位压力每轮推 0.04%
- **首轮冲击主要由这个参数决定**
- 想整体变强 → 调大；想整体变弱 → 调小

### 3. 每轮衰减 `playerImpactDecay`

压力每轮乘以这个系数：

```
第 1 轮：压力 P        → 推动 P × 系数
第 2 轮：压力 P × 0.88 → 推动 P × 0.88 × 系数
第 3 轮：压力 P × 0.88² → 推动 P × 0.88² × 系数
...
```

- 调**大**（0.95）→ 衰减慢，影响持续久，累计幅度大
- 调**小**（0.6）→ 衰减快，影响短促，累计幅度小

**总影响 = 首轮影响 ÷ (1 − 衰减系数)**

| 衰减系数 | 总影响 ÷ 首轮 | 90% 用完需要 |
|---|---|---|
| 0.95 | 20.0 倍 | 45 轮（225 秒） |
| 0.88 | 8.3 倍 | 18 轮（90 秒） |
| 0.80 | 5.0 倍 | 10 轮（50 秒） |
| 0.70 | 3.3 倍 | 6.5 轮（33 秒） |
| 0.60 | 2.5 倍 | 4.5 轮（23 秒） |
| 0.50 | 2.0 倍 | 3.3 轮（17 秒） |
| 0.40 | 1.7 倍 | 2.5 轮（13 秒） |

### 4. 后续影响倍率 `playerImpactTail` ★新增

**专门用来「首轮不变、后面调低」。**

- 第 1 轮永远按 1 倍算（不受这个参数影响）
- 第 2 轮起，每轮推动再乘这个倍率
- 但**衰减速度不变**，所以影响的「持续时间」基本不变

| 后续倍率 | 首轮冲击 | 累计影响 | 倍数 | 90% 用时 |
|---|---|---|---|---|
| 1（默认） | 0.048% | 0.394% | 8.2 倍 | 90 秒 |
| 0.8 | 0.048% | 0.325% | 6.8 倍 | 85 秒 |
| 0.6 | 0.048% | 0.256% | 5.3 倍 | 85 秒 |
| 0.5 | 0.048% | 0.221% | 4.6 倍 | 85 秒 |
| 0.4 | 0.048% | 0.186% | 3.9 倍 | 80 秒 |
| 0.2 | 0.048% | 0.117% | 2.4 倍 | 75 秒 |
| 0 | 0.048% | 0.048% | 1.0 倍 | 5 秒 |

（以成交 12 万、参考额 10 万、推力 0.0004、上限 4% 计算）

### 5. 单轮最大影响 `playerImpactMax`

压在单轮推动上的天花板，防止一笔巨单把价格瞬间打飞。

- 写成 **0.04** = 单轮最多 4%
- 写成 **0.008** = 单轮最多 0.8%
- ⚠️ 写成 **4** 就等于没有上限（400%），会出问题

### 6. 压力上限 `playerImpactFlowMax`

压力最多堆到多少单位。

- 12 表示：不管多大的单，压力最多 12 单位
- 12 × 0.0004 = 单轮最多推 0.48%
- 累计影响上限 = 12 × 0.0004 ÷ (1−0.88) ≈ **4%**

## 三、想「首轮冲击不变、后续影响调低」的两种做法

### 做法 A：只调「后续影响倍率」（推荐）

```
管理面板 → 市场冲击 → 后续影响倍率
```

- 保持 **0.5**：首轮冲击完全不变，累计影响从 8.2 倍降到 4.6 倍
- 保持 **0.3**：累计影响降到 3.2 倍
- 保持 **0**：只有首轮那一下，之后完全不推动

**优点**：影响的持续时间不变，价格走势的形状更自然，只是「余波」变弱。

### 做法 B：调「每轮衰减」

```
管理面板 → 市场冲击 → 每轮衰减
```

- 从 0.88 调到 **0.7**：首轮不变，累计影响从 8.3 倍降到 3.3 倍，同时持续时间从 90 秒缩到 33 秒

**优点**：不用新增参数；**缺点**：影响的「持续时间」也跟着变短，大单的余韵会变得很急促。

### 两者一起用

```
后续倍率 0.6 + 衰减 0.75
```

首轮不变，累计影响约 2.3 倍，持续约 45 秒——**短促而温和**。

## 四、和「每轮成交上限」的关系

大单不是一次成交的，而是按 `maxFillNotionalPerTick` 每轮成交一批：

```
一笔 100 万的单，每轮上限 30 万 → 分 4 轮成交
每成交一批，就往压力里加一批
```

所以「首轮冲击」指的是**第一批成交**带来的冲击。后面每成交一批，都会重新触发一次「首轮全额」的推动。

想减少大单的整体影响，除了调上面几个参数，也可以**调低每轮成交上限**，让压力分摊到更多轮、每次更小。

## 五、当前线上值（供对照）

| 参数 | 线上值 | 备注 |
|---|---|---|
| 参考成交额 | 100000 | 10 万 = 1 单位 |
| 推力系数 | 0.0004 | 每单位每轮 0.04% |
| 每轮衰减 | 0.88 | 8.3 倍放大 |
| 后续影响倍率 | 1 | 尚未启用折扣 |
| 单轮最大影响 | **4** | ⚠️ 应为 0.04，现在等于无上限 |
| 压力上限 | 12 | 累计上限约 4% |
| 每轮成交上限 | 1000000 | 100 万/轮 |
| 冲击成本系数 | 0 | ⚠️ 已关闭，洗单防护失效 |

### 建议修正

```
单轮最大影响：4 → 0.04      （否则一笔巨单可以瞬间把价格推飞）
冲击成本系数：0 → 6         （否则大单来回洗又能赚钱）
```

## 六、速查：不同目标该调哪个

| 想要的效果 | 调什么 | 方向 |
|---|---|---|
| 首轮冲击不变，余波变弱 | 后续影响倍率 | 调小 |
| 首轮冲击不变，但结束得更快 | 每轮衰减 | 调小 |
| 大单整体推得更猛 | 推力系数 | 调大 |
| 小单也能推动价格 | 参考成交额 | 调小 |
| 限制单笔最大冲击 | 单轮最大影响 | 调小（注意别写成 4） |
| 限制大单累计上限 | 压力上限 | 调小 |
| 让大单拆得更细 | 每轮成交上限 | 调小 |
