# XDstock 成就系统设计（v0.1 · 只策划未实现）

> 状态：**第一版已落地 —— 只做了 §9「主题专属成就 + 主题进化」**（普通/稀有/史诗三档还没做）。
> 落地实现见 `src/achievements.js`、`tests/theme-evolution.mjs`，细节说明见
> [`开发者文档.md`](开发者文档.md) §6.19。
> 面向的现状：5 秒一轮、9 只个股 + 2 个指数、主题买断 200 万、等级 Lv.1 起、无每日任务。

---

## 1. 一句话

四档成就（**普通 / 稀有 / 史诗 / 主题专属**）+ **主题进化**：
完成某个主题的两条专属成就，该主题升到 **Ⅱ 阶**，技能数值变强、外观多一层进阶标记。

---

## 2. 设计目标 / 非目标

**目标**

1. 给长期玩家一条新目标轴 —— 现在只有「等级 / 排行榜 / 总资产」三条，中后期很容易腻。
2. 让主题从「一次性 200 万买断」变成**可养成**的东西，买了还有追求。
3. 给「玩得花」的玩家奖励：不只有「赚得多」，还有「用技能用得漂亮」。

**非目标（明确不做）**

| 不做 | 原因 |
|---|---|
| 每日任务 / 签到 / 体力 | 5 秒一轮的群游戏，不需要额外打卡机制 |
| 用现金当主要奖励 | 会通胀，直接破坏排行榜 |
| 成就点兑换商城 | 首版只做展示，兑换留到 v2 |
| 赛季重置 | 主题进化是长期资产，重置会伤感情 |

## 3. 核心概念

| 概念 | 说明 |
|---|---|
| **成就点 AP** | 只增不减的累计值，用于展示和「Lv.3 商店」之类的前置 |
| **档位** | 普通 ★ / 稀有 ★★★ / 史诗 ★★★★★ / 主题专属 ◆ |
| **主题结晶** | 主题专属成就的产出，`player.shards[theme]`，用来进化该主题 |
| **主题阶** | `player.themeTier[theme]`：1 = 原版，2 = 进化后（本期只设计到 2 阶） |
| **称号** | 展示在昵称旁（可关闭），个别称号带极小的被动（≤2%），默认不带 |
| **进度** | 每个成就记 `progress / target`，前端显示进度条，不做「隐藏到 100%」的折磨 |

**防止数值爆炸的三条自律**

1. 进化只提升**技能手感**（返现比例、CD、信息量），不碰本金、不碰撮合上限。
2. 成就奖励**不发大额现金**：AP + 称号 + 结晶，最多发小额纪念金（≤5 万，象征性）。
3. 进化后的收益提升控制在 **30%~60%**，不动摇「本金为王」的基本盘。

## 4. 数据模型（实现时照抄）

```js
// ① 定义：写死在代码里，不进 db.json
export const ACHIEVEMENTS = [
  {
    id: 'trade_first',
    name: '第一笔',
    tier: 'common',            // common | rare | epic | theme
    theme: null,               // tier === 'theme' 时填 'red' / 'night' …
    desc: '完成第一次开仓',
    target: 1,                 // 进度目标
    counter: 'tradeCount',     // 对应玩家计数器
    hidden: false,             // 隐藏成就（解前显示 ???）
    reward: { ap: 5, shard: 0, title: null }
  },
  // …
];

// ② 玩家侧（db.players[id]）
p.achv = {                     // 只有「有进度」的成就才存，省空间
  trade_first: { p: 1, at: 1793000000000, seen: true },
};
p.achvPoints = 0;
p.shards = { red: 0, bear: 0, dark: 0, tycoon: 0, hermit: 0, probe: 0, mind: 0, night: 0 };
p.themeTier = { red: 1, bear: 1, dark: 1, tycoon: 1, hermit: 1, probe: 1, mind: 1, night: 1 };
p.counters = {                 // 累计计数器（成就判定只读这里）
  tradeCount: 0, closeCount: 0, winCount: 0, loseCount: 0,
  maxSingleFill: 0, maxPositionValue: 0, peakEquity: 0,
  feePaid: 0, stampPaid: 0, dividendEarned: 0,
  stealSuccess: 0, stealEarned: 0, emojiSent: 0,
  tpslSet: 0, tpslFired: 0, limitFilled: 0, limitExpired: 0,
  channelLevel: 0, themePurchased: 0,
  // …按 §5 的条目补
};
```

**存储成本**：9 只票、每人 40 个成就键 × 约 40B ≈ 1.6KB/人；40 人 ≈ 64KB，对 2.5MB 的 db.json 可接受。

**判定模型**：只做「计数器 + 阈值」，**不在 tick 里遍历成就表**。
计数器在事件点 `+1`，然后只检查「这个计数器关联的几个成就」，命中的当场写 `p.achv[id]`。

## 9. 主题专属成就 + 进化

### 9.1 每个主题两条（挑战 + 累计）

| 主题 | 成就①（挑战，40 AP + 1 结晶） | 成就②（累计，40 AP + 1 结晶） |
|---|---|---|
| 🐂 红红的牛 `red` | **顺势收割**：指数处于「价 > MA5 > MA10 > MA30」时平仓 20 次 | **牛气冲天**：技能返现累计 5M |
| 🐻 绿绿的熊 `bear` | **熊市舞者**：指数处于「价 < MA5 < MA10 < MA30」平仓 20 次 | **熊口拔牙**：技能返现累计 5M |
| 🕶️ 暗黑大手 `dark` | **黑手**：使用该技能在同一股同一方向开仓累计10M后切换其他技能在该股平仓 | **推土机**：在其他玩家开仓后反方向交易推动股价，在其平仓后再平仓 |
| 🐊 金融大鳄 `tycoon` | **先知**：在金融板块财报「超预期」公布前10倍杠杆建仓，公布后平仓 | **信息差**：金融板块交易累计盈利 5M |
| 🧙 隐世仙人 `hermit` | **来去无踪**：在其他玩家交易后使用此技能在同一股中参与交易 | **孤狼**：单票持仓 > 10M |
| 🕵️ 暗中调查 `probe` | **软柿子**：在其他玩家建仓的股上反方向开仓 | **情报网**：累计调查 20 次 |
| 🧠 情绪读心 `mind` | **读心**：在对应的情绪极度强烈时顺势盈利 | **情绪交易员**：激活此技能的过程中盈利 10M |
| 🌙 夜行者 `night` | **很会偷**：单次偷钱金额大于9500元 | **趁人不备**：夜间偷钱成功 200 次 |

### 9.2 进化条件与效果

**条件**：该主题成就① ② 全部达成的**下一轮**自动可进化（也允许手动点「进化」，给玩家一个仪式感）+ 消耗该主题 2 枚结晶。

> 结晶来源只有这两条成就，所以「进化」等价于「把主题的两种玩法都玩明白」，
> 不存在花钱买进化的路径，也不影响现金。

**进化效果（Lv1 → Lv2）**

| 主题 | 现在（Lv1） | 进化后（Lv2） | 提升幅度 |
|---|---|---|---|
| 🐂 红红的牛 | 多头排列平仓返 **1%** 成交额 | 返 **1.5%**；多头排列期间**挂单手续费全免** | +50% |
| 🐻 绿绿的熊 | 空头排列平仓返 **1%** | 返 **1.5%**；空头排列期间做空**保证金 −20%** | +50% |
| 🕶️ 暗黑大手 | 成交冲击 **+5%** | **+8%**；自己吃到的冲击成本**返还 20% 现金** | +60% |
| 🐊 金融大鳄 | 提前 **20 轮**看金融财报 | 提前 **30 轮**；并能看到「这次会不会超预期」的历史命中率 | 信息量 + |
| 🧙 隐世仙人 | **50%** 成交不进公开记录 | **75%**；排行榜上自己的持仓市值模糊成「≈X」 | +25pp |
| 🕵️ 暗中调查 | 看 **1 个**持仓，CD **30 轮** | 看**全部**持仓 + 对方**成本价**，CD **20 轮** | 强 |
| 🧠 情绪读心 | 只有情绪条 | 情绪条 + **重掷倒计时** + 情绪方向分量数值 | 信息量 + |
| 🌙 夜行者 | 夜间偷钱 CD 60 → **5 轮** | CD → **3 轮**；夜间偷钱**不触发对方通知** | 强 |

**平衡约束（写进代码注释）**

- 红牛/绿熊的 `1.5%` 上限由 `redBonusRate` / `bearBonusRate` 配置控制，**不要**在代码里硬编码第二份；
  进化只是把玩家侧的倍率从 1.0 提到 1.5（`skillMult`），改配置即可整体调节。
- 夜行者 CD 3 轮是硬底线（再低会出现「每轮偷一次」的失控）。
- 隐世 75% 之后不再往上加（100% 等于全服看不见，破坏交易记录生态）。
- 大鳄提前 30 轮 < 一个完整财报周期（720 轮），只是「多 10 轮准备时间」。

### 9.3 外观（已按此实现）

- **独立「成就」页**（导航第 6 个 tab，`#view-achv`）：顶部成就点 + 总进度，
  下面是 8 张主题卡（桌面 2 列 / 手机 1 列），每张卡：emoji + 名字 + `Ⅰ`/`Ⅱ` 徽章
  + `成就 n/2 · 结晶 x/2` + 两条成就（进度条 + 说明）+ 右下角
  「进化到 Ⅱ 阶 ✦ / 结晶不足 / 未达成 / 已进化 Ⅱ 阶」
- 已进化的卡：金色描边 + 淡金渐变背景（`is-evolved`）
- 商城主题卡只保留一行摘要（`成就 n/2 · 结晶 x/2` + 「看成就 →」），明细不重复
- 排行榜名字旁边显示成就图标（`🐂` / `🐊`）：**一个主题两条成就都达成才会亮**，
  只解一条不上榜（避免「解了一半也挂个徽章」）；**只显示主题图标，不带 ✦ 之类的进化标记**

### 9.4 落地实况（2026-11 实现）

| 项 | 实现方式 |
|---|---|
| 判定挂点 | 开仓/平仓在 `src/trading.js`（返现倍率、保证金、冲击、黑手、推土机、先知、情绪、孤狼）；偷钱在 `server.js` 结算处；调查在 `api.js#investigatePlayer`；财报到点在 `src/engine.js#runReports` |
| 阈值 | 全部走 `db.config`（管理面板「主题成就 / 进化」分类可改），代码只留兜底默认值 |
| 进化 | `POST /api/theme/evolve`：校验「已购买 + 两条成就 + 结晶够」→ 扣 2 结晶、阶数置 2 |
| 结晶 | 每条主题成就解锁 +1，只有这一个来源，买不到 |
| 排行榜 | `leaderboardRows()` 下发 `achvEmojis`（如 `🧙✦`），名字后面直接显示 |
| 隐世 Ⅱ 阶 | 排行榜资产换成 `≈$X`（保留 2 位有效数字）+ `fuzzed: true` |
| 调查 Ⅱ 阶 | 一次看全部持仓（未进化只给 1 个，且不下发列表）+ 冷却 30 → 20 轮 |
| 情绪 Ⅱ 阶 | 情绪条下方多一行「情绪 x% · 重掷 N 轮 · 生效 N 轮 · 方向分量 x%」 |
| 大鳄 Ⅱ 阶 | 提前量 20 → 30 轮；引擎按最大提前量生成 `pendingReport`，按每个玩家的阶数下发 |
| 夜行 Ⅱ 阶 | 夜间偷钱冷却 5 → 3 轮，且**不再通知受害者** |

| 风险 | 对策 |
|---|---|
| 两个号对刷偷钱 | 同一对手 24 小时内只计 1 次；`total < 5,000` 的偷钱不计进度 |
| 小号刷「被偷/被调查」类成就 | 注册 < 7 天且总资产 < 10 万的账号不产出对方成就 |
| 挂单反复挂撤刷成交 | 只统计**真实成交**（`fill`），撤单 / 超时单独计数且只给隐藏成就 |
| 转账刷现金类成就 | 现金类成就只看 `peakEquity`（总资产峰值），不看单笔进出 |
| 前端伪造 | 所有判定只读服务端 `db.trades` / `db.players`，**不开放成就上报接口** |
| 市场休市时刷 | 休市期间所有成交类计数器冻结 |

## 13. 验收标准（数值节奏）

- 新号（`startingCash = 0`，靠打工起步）**1 小时内至少解锁 5 条**普通成就；
- 每天活跃 1 小时：**3~5 天**解完普通、**2 周**解 60% 稀有；
- 每条主题的进化平均耗时 **3~7 天**，且必须用到该主题的技能本身；
- 进化后技能收益提升 **30%~60%**，不改变排行榜格局（第一梯队仍是本金厚的）；
- 反刷用例全部通过（对刷、小号、挂撤、休市），无一条能凭空刷出。
