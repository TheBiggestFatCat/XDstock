# 小灯证券 · 网页版模拟炒股

> 维护者必读：[AGENTS.md](AGENTS.md)（速查）· [docs/开发者文档.md](docs/开发者文档.md)（完整）


从 AstrBot 插件版股市移植过来的网页版，本地运行、零后端依赖。

## 快速开始

```bash
node server.js
```

然后打开 http://localhost:8971

- 首次进入：填昵称 + **6 位 PIN** 自动开户，起始资金 $100,000
- 管理面板口令：见下方「线上部署」，可在管理面板里改
- 老账号还是 4 位 PIN 的：照常用旧 PIN 登录，进去后会被要求设置新 6 位 PIN
  （此时 token 只能用来改密码，其它接口全部 403）

### 发一条带跳转的公告

管理面板「管理 → 市场 → 发布公告」里，内容照写，**跳转链接**填站内路径（如 `/tournament`），
玩家的「市场快讯」里就会出现一个「查看 ›」按钮。命令行发也行（服务器上执行）：

```bash
PIN=$(node -e "console.log(require('/opt/xdstock/data/db.json').config.adminPin)")
TOKEN=$(curl -s -X POST localhost/api/admin/login -H 'Content-Type: application/json' \
  -d "{\"pin\":\"$PIN\"}" | node -e "let s='';process.stdin.on('data',d=>s+=d).on('end',()=>console.log(JSON.parse(s).token))")
curl -s -X POST localhost/api/admin/announce -H 'Content-Type: application/json' \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"text":"🏆 锦标赛 21:00 开赛","ticks":1440,"href":"/tournament"}'
```

`ticks` 是显示时长（轮，1 轮 ≈ 5 秒，1440 ≈ 2 小时，0 = 永久）。`href` 只接受 `/` 开头的站内路径，
填 `https://...` 会被拒绝。

> 服务器上原本的 QQ 机器人（astrbot / snowluma / t2i-service / dashscope-shim）
> 已经全部停止，并把重启策略改成了 `no`，开机不会自己起来。

## 技术栈

| 层 | 选择 | 理由 |
|---|---|---|
| 后端 | Node 内置 `http`，**零依赖** | 20 人级别不需要框架 |
| 实时推送 | SSE（`text/event-stream`） | 比 WebSocket 简单，浏览器自动重连 |
| 存储 | 单个 `data/db.json`，原子写入（tmp + rename） | 数据量小，直接可读可备份，不需要数据库 |
| 前端 | 原生 ES Module + 手写 CSS | 无构建步骤，改完刷新即可 |
| 图表 | [lightweight-charts](https://github.com/tradingview/lightweight-charts) 4.2.3（已本地化到 `public/vendor/`） | 专业 K 线，离线可用 |

> 为什么不数据库：20 个玩家 × 每天几万条记录，单文件 JSON 完全够用，还能直接用记事本改。
> 如果以后要扩展到几百人，把 `src/store.js` 换成 SQLite 即可，其它代码不用动。

## 玩法参数

### 时间与波动（已按 5 秒 tick 重新标定）

| 参数 | 值 | 说明 |
|---|---|---|
| `tickMs` | 5000 | 一轮 5 秒，一天 17280 轮 |
| `baseVolatility` | 0.0022 | 每轮对数收益标准差 → **日波动约 29%** |
| `meanReversion` | 0.00017 | 对数空间回归，半衰期约 5.7 小时 |
| `maxOrdersPerTick` | 1 | 每人每轮只能下一单 |

原 bot 是 120 秒一轮、每轮 ±3%，波动非常剧烈；这里按 `σ_tick = σ_day / √tick数` 反推，
把日波动压到 29%，比原来温和一大截，同时保留「看得见跳动」的手感。

### 标的特质（从 bot 原样搬运）

| 代码 | 名称 | 特质 | 效果 |
|---|---|---|---|
| TGW | 丰川集团 | 老钱 | 波动 ×0.6，回归 ×1.6 |
| MAMA | 无畏科技 | 赌场 | 波动 ×1.8，回归 ×0.5，轻微正漂移 |
| DFY | 肥鱼科技 | 话题驱动 | 平时波动 ×0.8，被新闻命中时冲击 ×2 |
| LU | 瑞幸咖啡 | 反转王 | 连跌 72 轮必反弹 4~8%，连涨必回落，波动 ×1.3 |
| NW | 奶蛙传媒 | 梗股 | 平时阴跌，每轮 0.025% 概率暴涨 25~60% |
| XJ | 弦卷财团 | 护盘 | 跌破合理估值 85% 时每轮 +2.5% 买盘 |
| XD | 小灯证券 | 券商 | 涨跌跟全市场成交笔数，边际递减，中枢自适应 |

> 梗股彩票、反转连击、券商敏感度都做过 **÷24 缩放**（bot 是 120s，这里是 5s），
> 否则频率会变成原来的 24 倍，直接失控。

**特性对玩家是隐藏的**：行情列表和图表头都不显示特质名，
`/api/market` 也不下发 `traitName` / `traitDesc`。
只有管理员面板里能看到，方便调参。

### 交易

- 做多 / 做空，杠杆 1~20 倍自定义
- 保证金 = 名义价值 ÷ 杠杆，手续费 0.05%，印花税 0.05%（平多方向）；
  大单另收**冲击成本**（自己推动价格的钱自己付）
- **杠杆越高，保证金越少，爆仓越近** —— 下单面板实时算出爆仓价
  （`爆仓价 = 开仓价 × (1 ∓ 1/杠杆)`，下单后按开仓均价重算）
- 只挂限价单，成交价取当时市价（不会比限价更贵）；押金按下单时的最坏成交价冻结，
  成交后多退少补，撤单/超时全额退回
- **让利**：挂单价默认按现价让 0.5%（可改 0~3%，存在本地），买高卖低，
  多数情况下一轮就能成交
- **两种下单方式**（下单卡片上的「下单方式」切换，默认传统挂单）：
  - 🟢 **传统挂单**：价格到线才成交，押金按最坏成交价冻结
  - 🟠 **简单模式**：市价单，不看挂单价，**下一轮直接按市价无条件成交**；
    押金多冻 3% 兜跳空，大单按每轮成交额度分几轮吃完
- 可给每个持仓单独设**止盈价 / 止损价**：
  - 输入框里改，或下单时直接填
  - **K 线图上会画出成本线、止盈线、止损线**，实时跟随
  - 每 tick 自动检查，触发后自动挂出平仓单，**下一轮按市价成交（跳空也能平掉）**
- 亏损吃光保证金 → **爆仓强平**，只亏保证金
- **每人每轮只能操作 1 次**（`maxOrdersPerTick`，可改）。这条是为了堵一个漏洞：
  小灯证券的涨跌由「全市场成交笔数」决定，如果不限次数，
  一个人疯狂开 1 股的小单就能把它拉到涨停。

### 锦标赛（`/tournament`）

独立赛区，和主市场完全隔离（自己的账、自己的价格、自己的排行榜），
用主站账号登录即可参赛，不改动主市场任何数据。

- **开赛时间**：默认排到下一个 21:00（服务器本地时间），到点自动开赛；错过就顺延到次日。
  本期想临时改时间，直接改存档里的 `tour.startAt`（时间戳即可，前端倒计时和文案都读它）
- **唯一标的**：留美外汇 **LMFX**（退市后重新上到赛区），
  股价由模拟的 AUD/JPY 汇率 × 8 倍杠杆驱动，和退市前同一套公式
- **起手 30 万日元**，1~20 倍杠杆、做多/做空，手续费 0.02%，保证金剩 5% 强平
- **打工**：现金不足 30 万时点一下，一次性补齐到 30 万，**次数不限**
- **夺冠线 2000 万日元**（剧情：把妈妈亏掉的 2000 万赚回来），
  第一个达成的人夺冠，赛区立刻冻结，排行定格
- 页面四个标签：**首页**（剧情 / 倒计时 / 进度 / 打工）、行情、我的、排行榜
- 本地调试不想等到开赛时间：`XD_TOUR_OPEN=1 node server.js` 强行开赛

### 丰川银行（高利贷）

- 固定三个档位：**$50,000 / $200,000 / $1,000,000**
- 每 **100 轮**（5 秒 × 100 ≈ 8.3 分钟）复利一次，默认 **3%**
  - 2 小时 = 14.4 期 → 到期约欠本金的 **1.53 倍**
- 借期 2 小时，**随时可以手动还款**
  - 「一次还清」：把现金尽力还完
  - 「还这么多」：部分还款，最低 $1,000
- 到期时 `总资产 < 欠款` → **判定破产**，昵称写进「天台楼下记录册」，永久禁止交易

### 休市

管理员在「管理 → 市场控制」里一键休市，**立即生效**：

| 暂停的东西 | 说明 |
|---|---|
| tick 推进 | `db.tick` 完全冻结，K 线不再生成新柱 |
| 价格 | 所有标的价格钉死 |
| 新闻 | 不生成新事件，已有的也不倒计时 |
| 止盈止损 / 爆仓 | 价格不动，自然不会触发 |
| 高利贷计息 | 按 tick 计息，tick 停了自然就停了 |
| 下单 / 平仓 | 接口直接返回 423「休市中，暂停交易」 |

开市时会把休市这段时间**补给所有贷款的到期时间**，不会因为关服把人的贷款关爆。
前端会有橙色横幅提示，下单按钮变灰。

### 管理面板

- 市场：一键休市 / 恢复开市
- 标的：停牌 / 复牌 / 退市（退市会强平所有持仓）
- 手动新闻：选标的、定冲击幅度、定持续轮数（不选标的 = 全市场）
- 参数：波动率、回归强度、手续费、印花税、最大杠杆、每轮下单次数、
  新闻概率、每 100 轮利率、借款期限、管理员口令…
  改完立刻生效，不用重启

## 新闻系统（机制照搬 bot 版）

代码在 `src/news.js`（文案）和 `src/engine.js`（机制）。

| 类型 | 机制 |
|---|---|
| **全球事件** | 每轮按概率触发，持续 30~90 轮，每轮对涉及标的施加 `trend` 的对数冲击；`companies` 为空 = 全市场 |
| **假消息** | 到期时自动生成辟谣，冲击取 `reverse = -t / (1 + t)`，**数学上正好把涨跌吐回去** |
| **晚消息** | 价格先动，消息延后 12~30 轮才公布（事后解释） |
| **突发** | 单公司一次性冲击（瞬间 -6%~-11% 或 +6%~+12%），另配一段余波 |

> 假消息和晚消息在界面上**和普通消息长得完全一样**，线索只藏在文案里
> （「网传」「传」「自称」）。否则玩家一眼识破，机制就白做了。

## 数据与备份

- 全部状态在 `data/db.json`（约 10~200 KB），**想重开一局直接删掉它**
- 首次启动会自动空跑 2400 轮，把 K 线铺满，不然开局图表是空的
- 进程收到 SIGINT/SIGTERM/exit 时会落盘
- 每轮 tick 后异步写入（合并 800ms 内的多次改动）
- **自动备份**：启动时 + 每 30 分钟复制一份到 `data/backups/`，保留最近 40 份。
  手滑删档可以捞回来：

  ```powershell
  Copy-Item data\backups\db-20261031-235521-boot.json data\db.json -Force
  ```

## 从 bot 搬了什么 / 没搬什么

搬了：7 只标的的全部特质与数值关系、灯证指数的合成方式（等权 `价格/初始价`）、
印花税规则（卖出单边、0.05%）、做空保证金与爆仓逻辑、新闻冲击模型、公司图标。

没搬：ETF（灯证 1/2/3/4 倍、比特币）、海车投行（镜像股）、历史行情记录、
QQ 群绑定、打工/彩票/抵押房产等社交玩法。
